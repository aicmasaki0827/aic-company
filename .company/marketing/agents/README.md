# マーケティング マルチエージェントシステム

## 概要
オーケストレーター（メインClaude）が複数のサブエージェントを調整し、
ユーザーの指示なしでアフィリエイト記事の生成・最適化を自律的に実行するシステム。

## エージェント構成

```
ユーザー
  ↕ 会話（オーケストレーターのみ）
オーケストレーター（メインClaude）
  ↕ Agent tool で並列起動
  ├── strategy.md  → 成約トピックの選定・コンテンツ計画
  ├── writer.md    → 記事執筆（複数記事は並列起動）
  ├── sns.md       → SNS投稿文作成（記事と並列起動）
  ├── creative.md  → サムネイルブリーフ作成（記事と並列起動）
  └── review.md    → 完成記事の成約チェック・修正
```

## オーケストレーターの動作ルール

### 自律運転モード（ユーザーが「任せる」「記事を増やして」等と言ったとき）

1. **現状把握**（オーケストレーター自身）
   - `content-plan/` のファイル数・最新番号を確認
   - 直近の記事スタイル比率を確認（CTA型 vs 読み物型）

2. **戦略フェーズ**（strategy エージェントを起動）
   - 既存記事リストを渡す
   - 次に作るべき3〜5トピックを取得

3. **制作フェーズ**（並列起動）
   - writer エージェント × トピック数（並列）
   - sns エージェント × トピック数（並列）
   - creative エージェント × トピック数（並列）

4. **品質チェックフェーズ**（review エージェントを起動）
   - 全制作物をチェック
   - 問題があれば自動修正

5. **完了報告**（オーケストレーター）
   - 作成した記事一覧
   - SNS投稿文サマリー
   - サムネイルブリーフ一覧
   - 次回への改善提案

### 単発指示モード（ユーザーが具体的な作業を依頼したとき）
- 必要なエージェントだけを起動する
- 例: 「article-48のSNS投稿文を作って」→ sns エージェントのみ起動

## 各エージェントの起動方法（オーケストレーター用）

```
Agent(
  description="[エージェント名]",
  prompt="""
  .company/marketing/agents/[filename].md を読み込み、指示に従って作業してください。

  ## タスク
  [具体的なタスク内容]

  ## 入力情報
  [必要な情報]
  """
)
```

## パフォーマンス指標
- 記事数: 目標100本（現在48本）
- スタイル比率: CTA型70% / 読み物型30%（調整可）
- レビュー合格率: 100%（全記事リンク形式OK）
