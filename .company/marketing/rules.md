## 1. アフィリエイトリンクルール【最重要】

### 絶対禁止
- 生URL（bare URL）を記事に直接貼ることは**禁止**
- 違反例: `https://px.a8.net/svt/ejp?a8mat=...`（行にURLだけある状態）

### 正しい形式
必ず Markdown リンク形式 `[テキスト](URL)` で記述する。

### アフィリエイトURL（A8.net）
```
https://px.a8.net/svt/ejp?a8mat=4AXA8D+64VVR6+58IO+5ZEMP
```

## 2. 記事スタイル

### CTA型（article-01〜37）

**構成:**
1. 導入フック（共感・問題提起）
2. 本論（解決策・情報・メリット）
3. CTA①（中盤）← ここにリンク
4. 補足情報・FAQ
5. CTA②（末尾）← ここにリンク

**CTA形式:**
```
👇 **[CTA文言](https://px.a8.net/svt/ejp?a8mat=4AXA8D+64VVR6+58IO+5ZEMP)**
```

**CTA文言の例:**
- `無料で転職サイトに登録する（所要5分）`
- `無料登録して「定時退社できる求人」を見てみる`
- `まず登録してエージェントに相談してみる（無料・5分）`

**文字数・分量:** 80〜100行程度

---

### 読み物型（article-38以降）

**ルール:**
- CTAは**末尾1箇所のみ**
- 「今すぐ」「無料登録」「所要5分」等の**煽り表現禁止**
- サービス誘導表現なし

**CTA形式:**
```
[文脈に沿った自然なテキスト](https://px.a8.net/svt/ejp?a8mat=4AXA8D+64VVR6+58IO+5ZEMP)
```

**リンクテキストの作り方:**
- 直前の段落の「行動」を端的に言い換える
- 例: 「転職サイトで求人を眺めてみるだけでも」→ `[転職サイトで求人を眺めてみる]`
- 例: 「今の自分が転職市場でどう評価されるか」→ `[転職市場での自分の評価を確認してみる]`

**構成:**
1. 導入（体験談・視点・問い）
2. 本論（考察・深掘り・気づき）
3. 締め（読者への問いかけ or 気づきの共有）
4. リンク（自然な流れで1箇所）

**文字数・分量:** 60〜80行程度

## 4. 成約最適化ルール

### 高成約につながるトピックの特徴
- 悩みが**具体的・身体的**（残業、パワハラ、給料低い）
- **今すぐ逃げたい**感情がある状態
- 「自分だけじゃないかも」と思えるトピック
- 転職という解決策が**自然に**つながるもの

### 避けるべきパターン
- 情報提供だけで終わり行動を促さない記事
- 競合サービスと比較するだけの記事（成約先が分散する）
- ペルソナが広すぎる（「働く人向け」等）

### CTA配置の原則
- CTA前に**必ず読者の感情を高める文章**を置く
- CTAの直後に1行の補足（「逃げることは負けじゃない。」等）があると離脱率が下がる

## 5. マルチエージェント運用ルール

### エージェント呼び出しの原則
- オーケストレーター（メインClaude）が全体を管理
- ユーザーはオーケストレーターとのみ会話する
- 各エージェントは並列で起動できるものは並列で起動する

### 各エージェントのプロンプトファイル
```
.company/marketing/agents/
├── strategy.md   → 成約トピック選定
├── writer.md     → 記事執筆
├── sns.md        → SNS投稿文作成
├── creative.md   → サムネイルブリーフ
└── review.md     → 成約チェック
```

### 自律運転モードのトリガー
ユーザーが以下のように言ったとき:
- 「記事を作って」「増やして」「自律運転」「任せる」
- 具体的な指示がない場合 → 戦略エージェントからスタート
